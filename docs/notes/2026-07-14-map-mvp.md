# 2026-07-14 福生市人材資源マップ MVP

## 課題

断酒でGO!!から完全分離した新規リポジトリで、福生市民活動団体をLeaflet地図へ
表示する。公開確認前の連絡先・代表者情報は出さない。

## 実装方針

- 断酒でGO!!からLeaflet初期化、OSMタイル、MarkerCluster、静的JSON fetch、
  marker/popup描画の考え方だけを移植した。
- 例会日付、現在地、検索、PWA、断酒会固有データは移植しない。
- tyoの`/home/maji/fussa_jinzai.db`から`circles.json`を生成する。
- `is_hidden=0`かつ緯度経度ありだけを公開対象にする。
- verifiedは緑、needs_verificationは半透明の橙で表示する。
- popupは団体名、活動内容、正規化カテゴリ、未確認注記だけを表示する。
- 電話、メール、代表者、raw_fieldsは生成SQLにも出力構造にも含めない。

## 確認項目

- 静的JSON件数と31/61の表示内訳。
- 非表示団体と座標NULL団体がJSONに含まれないこと。
- 個人情報フィールドがJSONに含まれないこと。
- ローカルHTTP配信で地図、凡例、ピン、popupが表示されること。

## dry-run結果

- tyoの独立DBから公開用JSONを生成: 92件。
- 内訳: 位置確認済み31件、概算・未確認61件。
- `is_hidden=1`の5件と座標NULLの5件はJSON対象外。
- JSON各行はid、source_no、団体名、説明、カテゴリ、座標、確認フラグ、場所種別のみ。
- 電話、メール、代表者、raw_fields、contact_disclosure_statusは不存在をassert確認。
- Python unittest 2件、JavaScript構文検査、JSON件数・キー検査が成功。
- ローカルHTTP配信を実ブラウザで確認。地図、92件表示、31/61凡例、緑／橙ピン、
  verified/unverified両方のpopup、未確認注記が表示された。
- ブラウザconsoleのwarning/errorは0件。
