## ⚠️ プロジェクト共通ルール（すべてのエージェントが遵守）

- **作業開始前に必ず `git pull`**：`origin/main`との差分がないか確認してから着手する（2026-08-06、ローカルが3コミット遅れていた実例あり）
- **README.md「現在の状況」を編集する前に、必ず直前に`git pull`した実ファイルを基準にする**：チャットで渡された過去のコピーや、自分の記憶にある古い内容を基準にしない（2026-08-06、かもちゃんとふーちゃんが互いの版を見ないまま独立に更新しかけた実例あり）
- **断酒でGO!!とマジマップは完全に独立**：リポジトリ・DBともに混在させない
- **生データ層優先**：`raw_circle_submissions` を必ず経由してから正規化する
- **本番反映前に dry-run**：一括処理は必ず事前検証してから適用する
- **重複判定は本人確認が原則**：外見が似ている団体でも、団体自身からの申し出がない限り別団体として扱う（例：「男の台所」と「男の料理（H20）」は別団体として確認済み）
- **連絡先情報は `contact_disclosure_status` 確認まで非公開**
- **ジオコーディング**：ROOFTOP/APPROXIMATE → `needs_verification=0`／部分一致・種別不明・誤ジオコード確定 → `needs_verification=1`（座標はNULL化）
