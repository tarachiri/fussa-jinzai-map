# 2026-08-07 トップ画面の微調整（マップ高さ・文字サイズ・ヘッダー簡略化・ボタン化）

**担当エージェント**: ふーちゃん（Claude Code）

## 変更内容

- `#map`の高さを20%短縮（`calc(100vh - 66px)` → `calc(80vh - 53px)`、モバイルも同様に`calc(80vh - 78px)`。min-heightも同率で縮小）
- ヘッダー・タイトル（`.app-header`/`h1`）以外の文字サイズを全体的に拡大（凡例、地図ポップアップ、タグ、footer、提案バナー）
- ヘッダーから英語のeyebrow（「FUSSA COMMUNITY MAP」）とsubtitle（「地域で活動する団体を、地図から見つける試作版です。」）を削除。`h1`のみのシンプルな構成に変更
- 提案バナー内の「登録画面のイメージを見る →」リンクを、テキストリンクからボタン風スタイル（塗りつぶし・角丸・パディング）に変更

## 確認方法

Claude Browserでの画面キャプチャがこの環境では不安定だったため（`file://`の外部ファイルをスクロールすると画面が更新されない事象）、`javascript_tool`で`getComputedStyle`と DOM を直接検証し、以下を確認した:
- `.eyebrow`/`.subtitle` が存在しないこと
- `.proposal-card-link` の `background`/`color`/`padding`/`border-radius` がボタン然としたスタイルになっていること
- `#map` の計算後の高さが新しいcalc式に基づいていること
